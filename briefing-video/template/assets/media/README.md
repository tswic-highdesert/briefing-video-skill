# Hero media (optional)

The template opens and closes on a CSS gradient hero (`.hero` in `common.css`), so this folder can stay empty.

To use a hero video instead, put a file you own or have a licence for at `assets/media/hero.mp4` (1920x1080, 24-30 fps, 8-12 s) and follow "The hero" in `references/style.md`.
