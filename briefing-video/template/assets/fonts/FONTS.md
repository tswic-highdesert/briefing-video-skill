# Fonts

All three fonts are from [Google Fonts](https://fonts.google.com) and are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org), which allows bundling and redistribution with software.

| File | Family | Designer | Source |
|---|---|---|---|
| `YoungSerif.woff2` | Young Serif | Bastien Sozeau | https://fonts.google.com/specimen/Young+Serif |
| `InstrumentSans.ttf` | Instrument Sans (variable) | Instrument | https://github.com/google/fonts/tree/main/ofl/instrumentsans |
| `Caveat.woff2` | Caveat | Impallari Type | https://fonts.google.com/specimen/Caveat |

To use different fonts, replace these files and update the `@font-face` rules at the top of `common.css`. Keep the CSS family names (`"YS"`, `"IS"`, `"Hand"`) so the scene files keep working.
